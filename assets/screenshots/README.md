## 📷 화면 캡처 방법

### Android
- 전원 + 음량↓ 동시 누름 (1~2초)
- 또는 알림창 → **"화면 캡처"** 빠른설정

### iPhone
- 측면 버튼 + 음량↑ 동시 누름

### PC로 옮기기
- USB 케이블로 폰 연결 → `DCIM/Screenshots/` 폴더에서 복사
- 또는 카톡 "나에게 보내기"로 전송

---

## 🎨 캡처 권장 사양

- **해상도**: 1080×2400 또는 원본 해상도 그대로 (자동 리사이즈됨)
- **포맷**: PNG (JPG도 가능)
- **민감 정보 처리**: 이메일·전화번호 등은 모자이크 또는 더미 데이터 사용
  - 예: 이메일 `parent@example.com`, 코드 `K8N3RP`

---

## ✅ 캡처 후 확인

1. 모든 파일을 이 폴더(`assets/screenshots/`)에 저장
2. 루트의 `USER_GUIDE.md`를 열면 자동으로 이미지가 표시됨
3. 빠진 이미지는 깨진 이미지 아이콘으로 표시되니 확인하여 추가
